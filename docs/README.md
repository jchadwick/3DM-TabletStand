# Documentation Guide

Use these documents in this order when resuming work:

1. [`../AGENTS.md`](../AGENTS.md) — always-loaded operating rules and fit-critical context.
2. [`current-design.md`](current-design.md) — the current, actionable specification.
3. [`decision-log.md`](decision-log.md) — confirmed measurements and decision history.
4. [`validation.md`](validation.md) — required build, validation, and preview checks.
5. [`design-brief.md`](design-brief.md) — original conversation context, source provenance, and open questions.

`build/v1/README.md` describes generated artifacts only; it is not the authority for design decisions.
