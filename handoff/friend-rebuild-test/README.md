# 2024 onn. 8-inch tablet stand — clean-room rebuild packet

This packet contains the original user-supplied reference assets, a selected set of the user's prompts reproduced verbatim, and a consolidated dimensions/requirements sheet.

The packet intentionally does **not** contain the existing stand CAD, generated previews, dimensions taken from that stand, or descriptions of how the current model was implemented. It is intended to let another designer make an independent solution from the original device, cable, mounting, and aesthetic requirements.

Start with:

1. `PROMPTS.md` — selected standalone prompts in the user's exact wording.
2. `DIMENSIONS-AND-REQUIREMENTS.md` — consolidated physical inputs, clarified requirements, conflicts, and unknowns.
3. `ASSET-MANIFEST.md` — provenance and checksums for every supplied asset.
4. `assets/` — the original OBJ/MTL and all three attached images.

Important: `codex-clipboard-17350a1e-0ddd-494b-af0b-a246416a2dfd.png` depicts an early 10°-above-horizontal interpretation that the user later superseded. The final requested orientation is kiosk-like: 10° back from vertical (80° above horizontal), with the top edge farther from the user than the bottom edge.
